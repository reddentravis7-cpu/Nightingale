## History

The four per-domain crew charters — Researcher, Steward, Field Engineer, Research Specialist — predated CCO and were **grandfathered as operative** under CCO §4 from the atomic Constitution-v2.0 + CCO-v1.0 ratification (2026-07-30) until individually re-ratified. On **2026-07-31** all four were re-ratified onto CCO v1.0, each gaining an explicit §6 obligations-discharge mapping (they already named CCO v1.0 in their headers). **The grandfather window is now closed.**

When CCO is next amended (→ v1.1+), each role re-ratifies deliberately per CCO §4 rather than upgrading automatically, and this table is updated to show which version each role is on.
